# 톡방 Wrapped PRD

최종 수정: 2026-10-29 · 원본 기획 문서를 현재 구현에 맞게 정리한 버전

## 한 줄 정의

카카오톡 단톡방 내보내기 파일을 올리면 멤버별 성격, 관계·궁합, MBTI 추론, What's in my bag까지 "단톡방 Wrapped" 형식으로 보여주고, 방 멤버들이 링크로 같이 들어와 놀 수 있는 웹 서비스.

## 배경

100일·8만 메시지·5명 단톡방을 사람이 수작업으로 분석해 봤더니 반응이 좋았다. 숫자 통계, 기간별 줄거리, 멤버 분석, MBTI, 어워드, 인마이백 프롬프트까지 만드는 데 반나절이 걸렸다. 이걸 업로드 한 번으로 자동화한다.

## 목표

- 10만 줄 기준 업로드부터 결과까지 5분 이내
- 모든 해석에 원문 인용 근거를 붙여서 "그럴듯한 운세"가 아니라 "맞네" 소리가 나게 한다
- 결과를 단톡방에 링크·카드 이미지로 바로 공유한다
- 인프라는 무료 티어, 비용은 LLM 호출에만 (방 1개 분석 1달러 이하)

## 비목표 (MVP 제외)

- 카카오톡 외 메신저
- 대화 원문 서버 저장·검색
- 앱, 결제, 회원 간 소셜 기능
- 서비스 안에서 이미지 직접 생성 (프롬프트만 제공)

## 사용자와 시나리오

| 사용자 | 상황 | 원하는 것 |
| --- | --- | --- |
| 업로더 (방장·분위기 메이커) | 100일, 송별, 연말 같은 기념일 | 단톡방에 올릴 웃긴 결과물, 카드 이미지 |
| 방 멤버 (구경꾼) | 공유 링크로 접속 | 내 분석과 MBTI, 누구랑 제일 잘 맞는지, 퀴즈 |

1. 업로더가 카카오톡에서 대화를 내보내 zip/txt/csv를 올린다.
2. 분석할 기간을 고르고, 멤버를 확인하고(별명 묶기, 봇 제외, 별명 입력), 동의를 체크한다.
3. 분석이 도는 동안 구간별 진행률과 중간 발견을 본다.
4. 결과(스토리 슬라이드 → 리포트)를 본다.
5. 공유 링크를 단톡방에 보낸다. 멤버는 링크로 들어와 내 카드를 뽑고, 퀴즈를 풀고, 반박한다.

## 디자인 가이드

결과는 **단톡방 Wrapped** 형식. 먼저 세로 스토리 슬라이드로 몰입시키고, 끝나면 스크롤 리포트에서 근거를 파고든다.

참고 서비스: 톡랭크(카톡·라인 통계 iOS 앱, 인사이트 카드·랭킹), 채팅분석기(분할 파일 등록, 기간 선택), Yapd(WhatsApp Wrapped, 20장 애니메이션 슬라이드·아키타입 라벨·브라우저 파싱), Unwrapped(WhatsApp Wrapped, AI 성격 유형). 이들에 없는 **원문 인용 근거, 관계·궁합, 인마이백**이 차별점이라 가장 눈에 띄게 둔다.

원칙

- 한 장에 큰 숫자 하나, 설명 한 줄 ("흠 1,175번")
- 멤버는 색으로 기억: 업로드 때 고유색 배정, 어디서나 같은 색 (`src/lib/ui/colors.ts`)
- 모든 주장에 "근거 N개" 칩 → 원문 인용(날짜) 펼침
- 멤버마다 아키타입 한 줄이 프로필 제목
- 공유가 기본: 모든 슬라이드·카드 PNG 저장, 구석에 서비스 이름
- 수위 높은 놀림·궁합 카드는 스토리에서 빼고 리포트 안에만

스토리 슬라이드 순서 (기본 12장)

1. 오프닝: 방 이름, 기간, "100일, 메시지 80,073개"
2. 수다왕 랭킹
3. 말버릇 왕
4. 시간대 히트맵: 누가 밤에 살아나나
5. 숨은 기록 (이스터에그 1장)
6. 줄거리 3~5막
7. 멤버별 아키타입 (1인 1장)
8. 관계도와 최고 궁합 한 쌍
9. MBTI: 본인 주장 vs 행동 추론
10. 어워드
11. 인마이백 (픽셀)
12. 총평, 공유 버튼, 퀴즈 시작 버튼

## 개인정보·윤리

- 원문은 브라우저에서 파싱하고, AI 분석 요청 동안만 서버 메모리를 거친다. 저장·로그 금지.
- 전화번호·계좌·주민번호·이메일은 보내기 전에 브라우저에서 마스킹 (`privacy.ts`).
- 분석 시작 전 "방 멤버들에게 알리고 동의를 받았다" 체크 필수.
- 공유 링크: 추측 불가능한 슬러그, noindex, 기본 30일 만료, 업로더 삭제 가능.
- 민감 주제(건강·정신건강·자해·종교·성적 지향·연애 사생활·범죄·돈 문제)는 분석·어워드·퀴즈에서 제외.
- MBTI·궁합·가방은 전부 "추론"으로 표시하고 확신도를 같이 보여준다.
- 공개 전 개인정보처리방침 작성과 법무 검토 (해외 AI API 전송 명시).

## 기술 스택

Next.js 16 (App Router, cacheComponents) · Tailwind CSS 4 · Jotai · TanStack Query · JSZip · Zod · Vitest · OpenAI API (Structured Outputs) · Supabase (Postgres, Realtime Broadcast) · html-to-image · Vercel.

## 리스크

- 카카오톡 내보내기 형식 변경 → 형식별 테스트, 실패 시 "형식 제보"로 문제 줄만 받기
- LLM 환각 → 인용 원문 대조 (구현됨)
- 상처 주는 결과 → 민감 주제 필터, "이 항목 숨기기"
- 무료 티어 초과 → 대기열과 일일 한도
